# Telegram-бот с оплатой через Telegram Stars ⭐️

Готовый бот на Node.js ([Telegraf](https://telegraf.js.org/)), который показывает каталог
товаров и принимает оплату во внутренней валюте Telegram — **Stars**. Никакого
внешнего платёжного провайдера (Stripe, ЮKassa и т.п.) не требуется — Stars
обрабатываются напрямую серверами Telegram.

## Что уже сделано в коде

- `/start`, `/shop` — показывают каталог товаров инлайн-кнопками.
- Нажатие на товар → бот отправляет счёт (`sendInvoice`) в звёздах.
- Обработка `pre_checkout_query` — обязательное подтверждение перед списанием денег.
- Обработка `successful_payment` — бот благодарит и логирует оплату в консоль.
- `/refund <charge_id>` — команда владельца бота для возврата звёзд покупателю.
- Каталог товаров лежит в `src/products.js` — просто список объектов
  `{ id, title, description, priceStars }`.

## Шаг 1. Получить токен бота

Вы уже создали бота через [@BotFather](https://t.me/BotFather) — значит у вас есть токен вида
`123456789:AAExampleToken...`. Если токена нет под рукой:

1. Откройте чат с `@BotFather`.
2. Отправьте `/mybots` → выберите вашего бота → **API Token**.

## Шаг 2. Установить зависимости

```bash
cd telegram-stars-bot
npm install
```

## Шаг 3. Настроить переменные окружения

```bash
cp .env.example .env
```

Откройте `.env` и впишите:

```
BOT_TOKEN=токен_от_botfather
ADMIN_ID=ваш_telegram_id
```

`ADMIN_ID` нужен только для команды `/refund` (узнать свой id можно у бота
[@userinfobot](https://t.me/userinfobot)). Если возвраты не нужны — можно оставить пустым.

## Шаг 4. Запустить бота

```bash
npm start
```

В консоли появится `Бот запущен и слушает Telegram (long polling)`. Идите в Telegram,
напишите боту `/start` — увидите каталог.

## Шаг 5. Проверить оплату

1. Нажмите на любой товар в каталоге — придёт счёт (invoice) с кнопкой «Оплатить».
2. **Важно:** в обычном (не тестовом) режиме Stars списываются по-настоящему —
   у пользователя должен быть баланс звёзд (их можно купить прямо в Telegram).
   Комиссию за Stars-платежи Telegram не берёт, но при выводе денег на реальные
   средства (не звёзды) берётся комиссия — см. официальную документацию.
3. После оплаты бот пришлёт сообщение об успехе, а в консоли появится лог с
   `telegram_payment_charge_id` — он нужен, если захотите сделать возврат.

## Шаг 6. (Опционально) Сделать возврат

```
/refund <telegram_payment_charge_id>
```

Команда доступна только пользователю с `ADMIN_ID` и работает только для оплат,
совершённых после запуска текущего процесса бота (данные о покупках хранятся
в памяти — см. раздел «Что доработать для продакшена»).

## Как изменить товары / цены

Отредактируйте `src/products.js`:

```js
{
  id: 'coffee',            // уникальный идентификатор, используется в payload
  title: 'Чашка кофе',     // название, видно в счёте
  description: '...',      // описание в счёте
  priceStars: 50,          // цена в звёздах (целое число, БЕЗ умножения на 100)
}
```

## Как задеплоить, чтобы бот работал 24/7

Сейчас бот работает через long polling (опрашивает Telegram сам) — этого
достаточно для большинства случаев. Варианты хостинга:

- **VPS** (например, обычный Linux-сервер): скопировать папку, `npm install`,
  запустить через `pm2 start index.js --name stars-bot` или через systemd-сервис,
  чтобы бот перезапускался при падении/перезагрузке сервера.
- **Railway / Render / Fly.io** — задеплоить как обычное Node.js-приложение,
  указать переменные окружения `BOT_TOKEN` и `ADMIN_ID` в настройках сервиса.
- **Docker**: добавить простой `Dockerfile` (`FROM node:20-alpine`, `COPY`,
  `npm ci --omit=dev`, `CMD ["node", "index.js"]`).

Держать `.env` и токен в секрете — не коммитьте `.env` в git (он уже в `.gitignore`).

## Что доработать для продакшена

- Заменить `Map` в `src/bot.js` (переменная `purchases`) на настоящую БД
  (Postgres/SQLite/Redis), чтобы история покупок не терялась при перезапуске.
- Добавить выдачу купленного контента/доступа в обработчике `successful_payment`
  (сейчас там только благодарность — подставьте свою логику: выдать роль,
  разблокировать функцию, отправить файл и т.д.).
- При большом трафике — перейти с long polling на webhook
  (`bot.launch({ webhook: { domain, port } })`, см. документацию Telegraf).
